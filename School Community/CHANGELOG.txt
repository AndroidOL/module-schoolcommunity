CHANGELOG
=========

v1.4.0
------
- Add a Group Message Y/N mode to the normal send-message workflow.
- Send through an existing group or choose an eligible administrative/course
  class and create its controlled group when needed.
- Disable browser autocomplete on the direct recipient picker.

v1.3.1
------
- Include the thread archive/unread action route in the installed action map.

v1.3.0
------
- Search group names, group messages and replies with participant filtering.
- Search direct replies alongside direct message subjects and bodies.
- Add per-user archive/restore for direct and group threads.
- Add direct-message mark unread and group-thread mark unread actions.
- Automatically restore archived threads when new activity arrives.

v1.2.0
------
- Add administrative-class and course-class message groups.
- Show teachers only the class sources they are assigned to manage.
- Synchronize linked class membership from the current Gibbon class roster
  while keeping send-time recipient snapshots immutable.
- Keep one linked message group per administrative or course class.

v1.1.2
------
- Show group read totals only to the author of each group message.

v1.1.1
------
- Match Gibbon person IDs consistently when session and database values use
  different zero-padding, including group membership and self-message checks.
- Verify group snapshot SQL, sender access, read receipts and later-member
  denial against MySQL 8.4.

v1.1.0
------
- Allow users to send a category-eligible message to themselves.
- Add category-controlled message groups with owner-managed membership.
- Add recipient review, a frozen send-time recipient snapshot, group messages,
  replies, unread counts, read receipts and notifications.
- Prevent people added after a group message from seeing the earlier message,
  its replies or its receipt details.
- Require membership, active account and category audience checks for every
  group read and write.
- Add a 1.0.3 to 1.1.0 database upgrade for installed sites.

v1.0.3
------
- Filter recipients by the selected category audience before rendering the form
  and enforce the same rule again on submission.

v1.0.2

- Complete the reviewed Simplified Chinese translation pass.

v1.0.1

- Notify recipients about new messages and replies without blocking storage.
- Add a direct management link when no message categories are available.

v1.0.0

- Rebuilt message and category workflows for Gibbon 31.
- Added CSRF, POST, role, recipient, category and message-length validation.
- Added inbox, sent, unread and category filtering.
- Added read receipts, replies and strict participant access.
- Added English source strings and Simplified Chinese translations.
- Removed Help Desk data dependencies and debug/file logging.
