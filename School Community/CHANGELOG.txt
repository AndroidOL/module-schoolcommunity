CHANGELOG
=========

v1.4.6
------
- Move the target type, free-selection notice and create-group link onto the
  first Send Message page, directly below the Group Message toggle.
- Continue from the first page straight to the review-and-send page, removing
  the intermediate target step and its process endpoint.
- Resolve class, course and group targets at send time, creating the message
  group only when the message is actually sent.
- Show the recipient snapshot as a collapsed official details element on the
  review page instead of a modal link.

v1.4.5
------
- Rebuild message sending as a category, mode and target selection step followed
  by a review-and-send step.
- Add Free Selection group sending for at most 5 chosen recipients and direct
  users to create a group for larger audiences.
- Show a collapsed official recipient preview modal for class, course and
  existing group targets before sending.
- Replace browser delete confirmations with Gibbon modal confirmation pages for
  direct and group conversations.
- Redesign the direct message view using standard Gibbon DataTable, alert and
  form components.
- Add a Settings > Manage Message Groups page and remove the user Message
  Groups shortcut from category settings.

v1.4.4
------
- Restore only the current user's archived/deleted thread state when they send
  or reply, instead of clearing every participant's mailbox state.
- Correct linked group member counts and visibility in the group list and load
  each linked source membership only once per page view.
- Filter eligible recipients by role in SQL instead of loading every full user
  into PHP.
- Move group target switching into module.js and remove duplicate inline event
  handling.
- Route all Send Message page output through the page writer.

v1.4.3
------
- Keep the group target selector on the Send Message page while Free Selection
  opens the group page for choosing recipients.
- Show the standard-size Group Message toggle and switch direct, free and
  targeted group forms without reloading.
- Redesign direct message view with compact metadata, a readable message panel,
  standard action buttons and a structured reply list.
- Add Manage Message Groups to the Message Categories settings page.

v1.4.2
------
- Replace the separate recipient chooser with the original searchable direct
  recipient input.
- Switch group and direct modes in place without a page reload, and show the
  searchable class/group target only when Group Message is enabled.
- Keep a group target choice from submitting or triggering form validation.
- Compact detail metadata into localised inline lines and use smaller standard
  action buttons.

v1.4.1
------
- Add a repeat-safe 1.4.1 upgrade for installations that already consumed the
  original 1.4.0 schema version.
- Ensure the category group-message column exists and refresh the Send Message
  and View Messages action route maps with the recipient chooser, confirmation
  and group-recipient pages.

v1.4.0
------
- Add a per-category Group Messages switch, defaulting to enabled for existing
  and new categories, and enforce it in group creation and every send path.
- Add a Group Message Y/N mode to the normal send-message workflow.
- Send through an existing group or choose an eligible administrative/course
  class or official current-year Gibbon group and create its controlled group
  when needed.
- Replace the direct recipient field with a searchable modal recipient chooser
  that does not trigger browser autocomplete.
- Show message previews and standard Open/Archive/Delete actions in message lists.
- Add per-user Trash and restore for direct and group conversations without
  deleting shared messages or audit data.
- Give group conversations the same Active, Archived and Trash mailbox filters.
- Preview every resolved group recipient in a standard modal and block sends
  when the list is empty.
- Rebuild direct and group conversation details with official Gibbon form,
  typography, action and icon components.
- Require both Send Message and View Messages access before opening or
  processing any send workflow, so a stored message never lands on an
  unauthorised detail page.

v1.3.1
------
- Include the thread archive/unread action route in the installed action map.

v1.3.0
------
- Search group names, group messages and replies with participant filtering.
- Search direct replies alongside direct message subjects and bodies.
- Add per-user archive/restore for direct and group threads.
- Add direct-message mark unread and group-thread mark unread actions.
- Automatically restore archived threads when new activity arrives.

v1.2.0
------
- Add administrative-class and course-class message groups.
- Show teachers only the class sources they are assigned to manage.
- Synchronize linked class membership from the current Gibbon class roster

- Keep one linked message group per administrative or course class.

- Require membership, active account and category audience checks for every

- Add a 1.0.3 to 1.1.0 database upgrade for installed sites.
